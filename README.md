## About The Project

**Globalization Terminal: Absurdist Arcade Edition** is a client-side educational game that turns globalization concepts into an interactive arcade experience.

Players move through three stages:
1. **Geo-Guessr** — Drop pins on a rotating globe based on historical and economic clues.
2. **Flag Classifier** — Sort real country flags into **Core**, **Semi-Periphery**, and **Periphery** using World-Systems Theory.
3. **Global Feud** — A fast-paced answer board where players guess top responses under time pressure.

The experience is styled like a neon, surreal arcade with strong visual effects, glitch aesthetics, glowing UI, and animated transitions.

---

## Features

- **Surreal Arcade UI** — Neon visuals, glitch aesthetics, and animated transitions
- **Single-Page Architecture** — Built with React + Vite for lightning-fast loading
- **Fully Client-Side** — No backend, no database, no paid APIs required
- **Interactive Globe** — Pin placement, drag rotation, and scroll-to-zoom mechanics
- **Challenger Token System** — Async multiplayer using Base64 score sharing
- **Personal Best Tracker** — localStorage-based high score on your device
- **Educational Grimoire** — Dossier modal linked to course PDF materials
- **Global Sound System** — Procedural arcade music with toggle

## Getting Started

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/derrickernestperez/Globalization-Terminal.git
cd Globalization-Terminal
npm install
```

### Run locally

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build for production

```bash
npm run build
```
